# diditdwianto.github.io

- [`/dinner/`](https://diditdwianto.github.io/dinner/) — AI Leaders Dinner (Wonderful Indonesia): the guest page for ordering drinks by voice. Built output; source in [`dinner-src/`](dinner-src/).
- [`/guest-search/`](https://diditdwianto.github.io/guest-search/) — guests type their name to see their drink-order QR code. The guest list is in `guest-search/guests.json`; the QR is drawn with `qrcode-generator` 1.4.4, the Drinks Orders app's library.
